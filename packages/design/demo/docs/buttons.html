Docs Buttons

Buttons

7 variants, 3 sizes, loading state. Works on <button>, <a>, and [role="button"].

Variants

Use semantic classes to communicate intent.

<button class="pdx-primary">Primary</button> <button class="pdx-secondary">Secondary</button> <button class="pdx-ghost">Ghost</button> <button class="pdx-danger">Danger</button> <button class="pdx-success">Success</button> <button class="pdx-warning">Warning</button> <button class="pdx-info">Info</button>

Sizes

Add size="sm" or size="lg". Default is medium.

<button class="pdx-primary" size="sm">Small</button> <button class="pdx-primary">Medium</button> <button class="pdx-primary" size="lg">Large</button>

Disabled

<button class="pdx-primary" disabled>Disabled</button>

Loading

Add pdx-loading class. Text becomes invisible, spinner appears.

<button class="pdx-primary pdx-loading">Saving</button>

Full Width

Add [full] attribute for 100% width.

<button class="pdx-primary" full>Full Width</button>

Link as Button

Works on <a> with role="button".

Link Primary Link Secondary Link Ghost
<a href="#" class="pdx-primary" role="button">Link</a>
