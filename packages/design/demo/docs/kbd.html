Combinations

Wrap in pdx-kbd-combo for auto + separator.

CtrlC Copy CtrlShiftP Command Palette ⌘K Quick Search AltF4 Close Window

Sequences

Press keys one after another. Wrap in pdx-kbd-seq.

G then D Go to Dashboard G then S Go to Settings

Sizes

Ctrl sm Ctrl default Ctrl lg

In Context

Inline with text, in menus, in tooltips.

Press CtrlK to open the command palette.

Use Tab to move focus and Enter to confirm.

Navigate with ↑ ↓ arrows, press Esc to close.
