Pragmatic Design CSS

Context-driven CSS framework. Agent-first, human-friendly. 100+ components, 11 themes, ~12KB.

 Layout 6 primitives: stack, row, grid, center, cluster, split Surfaces Card, inset, overlay, glass, interactive Buttons 7 variants, 3 sizes, loading, disabled Form Controls Input, checkbox, radio, toggle, groups Typography 9 roles, ink colors, links, code Feedback Alerts, badges, skeleton, progress Data Display Tables, tabs, accordion, timeline Navigation Breadcrumb, pagination, stepper, navbar Overlays Dialog, drawer, tooltip, dropdown Media Avatar, images, video, figure Utilities Divider, truncate, sticky, snap

Quick Start

<link rel="stylesheet" href="@pdxui/design/src/pragmatic-design.css">

<html pdx-scheme="auto" pdx-theme="neutral" pdx-density="normal">

Architecture

@layer pdx.reset      — Modern CSS reset
@layer pdx.tokens     — 80+ custom properties
@layer pdx.layout     — 6 layout primitives
@layer pdx.surfaces   — Surfaces + buttons + inputs
@layer pdx.typography  — Text roles + ink colors
@layer pdx.media      — Images, avatar, embed
@layer pdx.components — Table, tabs, accordion...
@layer pdx.adaptive   — Container queries, touch, motion
@layer pdx.themes     — 11 themes (override tokens + structure)

Your CSS (unlayered) always wins.
