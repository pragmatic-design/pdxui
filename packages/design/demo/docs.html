Pragmatic Design CSS

Context-driven CSS framework. Agent-first, human-friendly. Every example below is live.

Layout

6 custom element tags for structure. CSS-only, no JavaScript.

Vertical flow. Children stack top to bottom.

Accordion

What is Pragmatic Design CSS?

A context-driven CSS framework that's agent-first and human-friendly.

How does dark mode work?

Uses CSS light-dark() function. Set pdx-scheme="dark" on html.

Is JavaScript required?

Only for adaptive behaviors (collapse, drawer). Layout is pure CSS.

<details class="pdx-accordion" open> <summary>Question?</summary> <p>Answer.</p> </details>
