# API reference

Generated from the source by `packages/site/scripts/gen-api.mjs` — every value export of
`@pdxui/core` and `@pdxui/router`, one page per module, with the specifier that actually
imports it. The prose pages are the place to start; this is the index they link into.

A symbol reachable only from a sub-path shows that sub-path. `mount` is in
`@pdxui/core/testing`, not in the barrel, and that distinction is what these pages exist
to make visible.

## Modules

- [Reactivity](/docs/api-reactivity) — Signals, computed values, effects, stores, watchers, signal operators, events and observers as signals, resources, queries, mutations and the cache. 70 exports.
- [Components](/docs/api-components) — Defining components, lifecycle hooks, provide and inject, slots, themes and schemes, permissions, icons, overlays and positioning, dialog and toast queues, selection, drag, sorting and gestures. 100 exports.
- [Rendering](/docs/api-rendering) — Templates, lists, conditional and deferred blocks, error boundaries, portals, transitions, keyframes, springs, tweens and the virtualizer. 62 exports.
- [Forms](/docs/api-forms) — Forms, fields, field arrays, validators, schemas and form-associated custom elements. 43 exports.
- [Data and HTTP](/docs/api-data) — The HTTP client and its middleware, uploads, data sources and transports, the data grid model, CSV and XLSX export, and the auth store. 55 exports.
- [Accessibility](/docs/api-accessibility) — Focus management, focus traps, roving tabindex, active descendant, live regions and the announcer. 14 exports.
- [Internationalisation](/docs/api-i18n) — Locales and translations, ICU messages, the $t, $d, $n and $r formatters, component strings and right-to-left direction. 33 exports.
- [Calendar](/docs/api-calendar) — Date arithmetic, month grids, week, quarter and fiscal ranges, ISO dates: the engine behind the date components. 30 exports.
- [Browser and device](/docs/api-browser) — Storage, online and idle state, the title and head, media queries, scroll, the splash screen, bottom sheets, pull-to-refresh, safe areas and the route trail. 20 exports.
- [Testing](/docs/api-testing) — Mounting a component in a test, queries by role, text and test id, events, typing and waiting. 14 exports.
- [Debugging and devtools](/docs/api-devtools) — The devtools entry point and overlay, the debug handle, telemetry and navigation recording. 8 exports.
- [Security and utilities](/docs/api-utilities) — URL sanitising and the development flag. 6 exports.
- [Router](/docs/api-router) — Creating the router, navigation, the current route with its params, query and loader data, guards, the outlet, links and prefetching. 28 exports.
