# Licensing

Everything in PDX is **MIT**: every package, the compiler and the component library included. Free
for everyone — in production and in commercial products, at any scale, with no threshold and no
paid tier.

| Package | License | What it is |
|---------|---------|------------|
| `@pdxui/core` | MIT | Signals, templates, components, forms, data, i18n |
| `@pdxui/design` | MIT | The CSS design system: tokens, 13 themes, the theme engine |
| `@pdxui/router` | MIT | `@page` routing, guards, lazy routes |
| `@pdxui/cli` | MIT | `pdx dev · build · check · new · theme` |
| `@pdxui/lsp` | MIT | The `.pdx` language server, used by the VS Code extension |
| `@pdxui/compiler` | MIT | The `.pdx` language: the Vite plugin that turns `.pdx` into Web Components |
| `@pdxui/ui` | MIT | The component library |
| `@pdxui/framework` | MIT | The runtime in one install |

Each package carries the full text in its `LICENSE` file and declares `"license": "MIT"` in its
`package.json`. The JavaScript the compiler emits into your project is yours.
